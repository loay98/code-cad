# Cad Research Skill: cad-research

## Purpose
**Goal**: Research mechanical components, manufacturer documentation, technical specifications, and existing CAD models.

### When to Use
- Need to research a specific component or system
- Looking for existing CAD models or designs
- Researching manufacturer specifications
- Investigating component standards or requirements
- Finding technical documentation and reference materials

### Prerequisites
- Access to web research tools (websearch, webfetch)
- Understanding of CAD terminology and concepts
- Ability to verify and source evidence for dimensions
- Access to external documentation and resources

### Procedure

#### Step 1: Define Research Requirements
1. **Identify Research Goal**: Determine the specific component or system being researched
2. **Specify Information Needs**: List all required data points (dimensions, materials, specifications, etc.)
3. **Establish Scope**: Define boundaries of the research (geographic, temporal, industry)
4. **Define Evidence Standards**: Determine what constitutes valid evidence

#### Step 2: Source Identification
1. **Primary Sources**: Search manufacturer websites, technical documentation
2. **Secondary Sources**: Industry standards, technical papers, CAD libraries
3. **Alternative Sources**: When primary sources unavailable, use credible secondary sources
4. **Source Evaluation**: Assess source credibility, completeness, and relevance

#### Step 3: Data Collection
1. **Direct Access**: Access manufacturer websites and documentation
2. **Download Materials**: Obtain relevant drawings, specifications, and data files
3. **Documentation**: Record source URLs, file formats, version information
4. **Citation**: Maintain proper attribution and licensing information

#### Step 4: Evidence Classification
1. **Manufacturer-Confirmed**: Data directly from manufacturers
2. **Physical Measurement**: Data from physical testing or measurement
3. **CAD Measurement**: Data extracted from existing CAD models
4. **Calculated**: Data derived from known parameters and relationships
5. **Estimated**: Data based on visual inspection or approximation
6. **Unknown**: Data that cannot be verified or estimated

#### Step 5: Analysis and Reporting
1. **Data Verification**: Cross-reference multiple sources for consistency
2. **Confidence Assessment**: Determine confidence level for each data point
3. **Documentation**: Create comprehensive research report with:
   - Source citations
   - Evidence types
   - Confidence levels
   - Uncertainty statements
4. **Validation**: Verify critical dimensions against physical tests when possible

### Key Principles
- **Evidence-Based**: All research must be backed by verifiable sources
- **Source Attribution**: Proper citation of all information sources
- **Transparency**: Clear documentation of assumptions and limitations
- **Verification**: Multiple source verification when possible
- **Quality Assurance**: Validation of data quality and completeness

### Success Criteria
- ✅ Research question clearly defined and answered
- ✅ All dimensions have documented sources
- ✅ Evidence classified and verified
- ✅ Research report is comprehensive and well-organized
- ✅ All sources are properly cited and accessible

### Tools and Resources
- websearch: For searching technical documentation and specifications
- webfetch: For accessing specific files and documentation
- Context7: For library documentation and technical references
- cad-mcp-server: For advanced CAD geometry analysis when available

### Output Formats
- **Research Report**: Detailed analysis with citations and evidence
- **Data Table**: Structured presentation of findings
- **Source Index**: Complete listcolor of all sources used
- **Validation Summary**: Assessment of data quality and confidence levels

### Common Challenges
- **Limited Sources**: When primary sources are unavailable
- **Data Conflicting**: When different sources provide contradictory information
- **Verification**: Difficulty in verifying the accuracy of third-party sources
- **Licensing**: Restrictions on accessing certain documentation or models

### Best Practices
- Start with primary sources whenever possible
- Cross-reference multiple sources for verification
- Document all assumptions and limitations
- Maintain a reproducible research process
- Ensure all measurements have proper source attribution

### Skill Usage Example
```
# Example usage of cad-research skill
Use cad-research to investigate the mounting plate requirements:

Research goal: Analyze mounting plate specifications for mechanical assembly
- Component: Standard mounting plate
- Required information: Dimensions, hole patterns, material specifications
- Timeframe: 24 hours
- Evidence requirements: Manufacturer data, CAD measurements, technical drawings
```
